# Class guestbook

Practice contributing to a project you don't own: fork → add a file → pull request.

## How to sign
1. Click **Fork** (top right), then **Create fork**.
2. In your fork, click **Add file → Create new file**.
3. Name it `guests/your-username.md` (typing `guests/` creates the folder).
4. Write a short hello: your name, what you study, one fun fact.
5. Commit, then click **Contribute → Open pull request**.
6. Give it a friendly title and click **Create pull request**.

Please only add your own file. One file per person means nobody's changes clash.
